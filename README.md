# Flappy Bird Game

A Flappy Bird clone developed in C# using SplashKit.

## Features

- Bird movement with gravity and jump mechanics
- Randomly generated pipe obstacles
- Collision detection system
- Real-time score tracking
- Animated cloud background
- Game Over screen
- Restart button functionality

## Technologies Used

- C#
- SplashKit SDK
- Object-Oriented Programming

## How to Play

1. Press the Spacebar to make the bird jump.
2. Avoid hitting pipes and screen boundaries.
3. Pass through pipe gaps to increase your score.
4. Click Restart after Game Over to play again.

## Concepts Practiced

- Structures (`Bird`, `Pipe`, `Cloud`)
- Lists and collections
- Collision detection
- Game loops
- Event handling
- Random obstacle generation
- Basic game physics
